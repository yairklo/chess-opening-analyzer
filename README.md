# ניתוח פתיחות – Lichess `yairklo`

אפליקציה מקומית (Python + Streamlit) שמורידה את 1000 המשחקים האחרונים, מנתחת את 20 החצאי‑מסעים הראשונים עם Stockfish,
מוצאת את הטעויות שלך בפתיחה, ומציגה עץ פתיחות, פתיחות בעייתיות, טעויות חוזרות ותרגול.

## התקנה

```bash
pip install -r requirements.txt
```

Stockfish: הבינארי הצפוי ב‑`engine/stockfish/stockfish-windows-x86-64-universal.exe`
(Stockfish 19 מ‑GitHub releases). אפשר להצביע על מנוע אחר עם משתנה הסביבה `STOCKFISH_PATH`.

## הרצה

```bash
python run_all.py                 # הורדה (אם data/games.ndjson לא קיים) + ניתוח מנוע
python run_all.py --refresh       # הורדה מחדש
python run_all.py <user>          # אותו דבר לשחקן אחר מ-Lichess
python -m chessapp.analyze <user> --quick   # רק תוצאות + עץ פתיחות, בלי מנוע (שניות)
python -m streamlit run app.py    # הדשבורד, ברירת מחדל http://localhost:8501
python report.py [user]           # סיכום בטרמינל
```

## שחקנים נוספים

בסרגל הצד של הדשבורד: **הוספת שחקן מ‑Lichess** – שם משתמש וכמה משחקים אחרונים (200 / 500 / 1000).
ההורדה לוקחת בערך דקה לכל 500 משחקים; עץ הפתיחות ומסך **נקודות חולשה** מוכנים מיד אחריה, כי הם מבוססים על תוצאות בלבד.
"הורד ונתח" מוריד ומפעיל מיד גם את ניתוח הטעויות ב‑Stockfish ברקע (אפשר לבטל בתיבת הסימון; כ‑0.65 שניות למשחק, עם פס התקדמות).
הלוג ב‑`data/analyze_<user>.log`; ניתוח נחשב כושל רק אם התהליך שלו (לפי ה‑PID בלוג) כבר לא רץ, לא לפי הזמן מהעדכון האחרון.
המשחקים נשמרים ב‑`data/games/<user>.ndjson`, ובטבלאות `game_results` / `errors` / `skipped` יש עמודת `user`
(טבלאות ישנות מוסבות אוטומטית לשחקן ברירת המחדל). הערכות המנוע משותפות לכל השחקנים לפי FEN, כך שעמדות נפוצות לא מנותחות פעמיים.
לשחקן אחר מסך התרגול מוסתר והטקסטים בגוף שלישי.

**נקודות חולשה**: כל צומת בעץ מוצג לפי הפער שלו מאחוז הנקודות הממוצע של השחקן באותו צבע, מהחלש לחזק.
"ודאות" משווה את הפתיחה **לשאר המשחקים** באותו צבע (מבחן z לשני שיעורים, כדי שהפתיחה לא תיכלל בממוצע שמולו היא נבדקת).
מאחר שנבדקות עשרות פתיחות במקביל הספים מחמירים: גבוהה = |z| ≥ 2.5 ולפחות 20 משחקים, בינונית = |z| ≥ 2 ולפחות 15, אחרת "ייתכן מקרי".
הסיכום מציג עד 3 חולשות ו‑3 חוזקות בוודאות בינונית ומעלה (בלי צמתים חופפים). אם אין כאלה, מוצגות שתי המועמדות הבולטות עם הסימון "ייתכן מקרי".

אופציונלי: טוקן אישי של Lichess (בלי הרשאות) ל‑Opening Explorer. יוצרים אותו ב‑
https://lichess.org/account/oauth/token/create?description=opening-analyzer ושומרים אותו בקובץ `data/lichess_token.txt`
(הטוקן לבד, או `LICHESS_TOKEN=...`). הקובץ נקרא בכל פעם, כך שאין צורך להפעיל מחדש, ותיקיית `data/` לא עולה לגיט.
אפשר גם משתנה סביבה `LICHESS_TOKEN`, שמקבל עדיפות על הקובץ.

## מבנה

- `chessapp/fetch_games.py` – הורדת NDJSON (`max=1000&opening=true&evals=true&clocks=false`), המתנה של דקה ב‑429.
- `chessapp/analyze.py` – ניתוח Stockfish במקביל (תהליכים), מטמון SQLite לפי FEN + גרסת מנוע והגדרות (`data/cache.sqlite`, טבלת `evals_v2`); כל הטעויות נשמרות בטבלת `errors`.
- `chessapp/stats.py` – עץ פתיחות, סטטיסטיקות, פתיחות בעייתיות, טעויות חוזרות, ייצוא PGN (הכל מחושב מחדש לפי הסינון).
- `chessapp/explorer.py` – Opening Explorer (מטמון בטבלת `explorer`, רק לעמדות הבעייתיות).
- `app.py` – הדשבורד (עברית, RTL; מסעים ושמות פתיחות באנגלית).

## ספים והגדרות (`chessapp/config.py`)

| הגדרה | ערך | משמעות |
|---|---|---|
| `ANALYZE_PLIES` | 20 | חצאי‑מסעים ראשונים שנבדקים |
| `ENGINE_DEPTH` | 16 | עומק קבוע, בלי מגבלת זמן (הערכות יציבות; חלק ממפתח המטמון) |
| `ERROR_WIN_DROP` | 12 | ברירת המחדל לירידה בסיכויי הניצחון שנחשבת טעות; ניתנת לשינוי בסרגל הצד (8/10/12/15/20) |
| `ERROR_STORE_MIN` | 6 | ירידות מהגודל הזה נשמרות, כך ששינוי הסף לא מצריך להריץ את המנוע שוב |
| `CONF_HIGH_Z` / `CONF_MID_Z` | 2.5 / 2.0 | ספי ודאות במסך החולשות (עם מינימום 20 / 15 משחקים) |
| `MIN_GROUP_GAMES` | 10 | מינימום משחקים לצומת בעץ הפתיחות |
| `LINE_MAX_PLIES` | 12 | עומק מקסימלי של רצף הפתיחה בעץ |
| `EARLY_ERROR_MOVE` | 8 | טעות "מוקדמת" = עד המסע ה‑8 של השחקן |
| `EARLY_ERROR_SHARE` | 30% | פתיחה בעייתית: לפחות 30% מהמשחקים עם טעות מוקדמת |
| `TOXIC_MARGIN` | 5% | פתיחה בעייתית: אחוז נקודות נמוך לפחות ב‑5 נקודות אחוז מהממוצע באותו צבע |
| `MIN_PROBLEM_GAMES` | 3 | טעות חוזרת = אותו מסע באותה עמדה ב‑3 משחקים לפחות (גם תנאי לפתיחה בעייתית) |
| `TREND_DAYS` | 30 | התקופה האחרונה שמושווית לכל מה שלפניה |

- **טעות**: מסע של השחקן שמוריד את סיכויי הניצחון (הנוסחה של Lichess: `50 + 50·(2/(1+e^(−0.00368·cp)) − 1)`) ב‑12 נקודות אחוז או יותר.
  כך ‎+5 ← ‎+4 (עדיין מנצח) אינה טעות, ו‑‎+0.5 ← ‎−0.7 כן. הניתוח **לא** נעצר בטעות הראשונה: כל הטעויות ב‑20 החצאי‑מסעים נשמרות.
  מסע שזהה למסע הטוב של המנוע לעולם לא נחשב טעות, גם כששני חיפושים נפרדים נותנים הערכות מעט שונות.
- **מטמון**: המפתח הוא FEN (בלי מוני מסעים, כך שטרנספוזיציות משתפות הערכה) + תג מנוע (`Stockfish 19|depth=16|threads=1|hash=64`).
  שינוי גרסה או הגדרות יוצר הערכות חדשות ולא מערבב עם הישנות.
- **עץ פתיחות**: לכל צבע, כל רצף (עד 12 חצאי‑מסעים) שמשותף ל‑≥10 משחקים הוא צומת; צומת עם המשך יחיד מושמט אם הוא לא מוסיף לפחות 10 משחקים משלו.
  כל שורה בטבלה סוכמת את כל המשחקים שמתחילים ברצף (כולל ההמשכים). השם: שם Lichess אם ≥60% מהמשחקים מסכימים עליו, אחרת שם המשפחה, אחרת "פתיחות שונות".
  העץ מחושב מחדש לכל סינון.
- **גמביטים**: מסע בתוך רצף הפתיחה שהמשחק שייך אליו (הצומת העמוק ביותר) הוא בחירה מכוונת ולא נספר כטעות. מאחר שהניתוח ממשיך, הטעויות שאחרי הגמביט כן נספרות
  (למשל ב‑Rousseau Gambit).
- **פתיחה בעייתית**: אותו כלל ודאות כמו במסך החולשות (לא "ייתכן מקרי"), אחוז נקודות נמוך מהממוצע **באותו צבע** ב‑5 נקודות אחוז לפחות, ≥30% מהמשחקים עם טעות מוקדמת אחרי רצף הפתיחה,
  **וגם** אותה טעות בדיוק (עמדה + מסע) ב‑≥3 משחקים.
- **טעויות חוזרות**: קיבוץ לפי עמדה + מסע; ברירת המחדל מציגה רק כאלה עם ≥3 משחקים, ולכל אחת גם את המסע שאתה משחק בעמדה בדרך כלל.
  מסע ששוחק ב‑≥5 משחקים וציונו מעל הממוצע של אותו צבע (גמביט שעובד) לא מוצג.
- **ציון** = (ניצחונות + ½·תיקו) / משחקים.

## הדשבורד

חמישה מסכים (ניווט בראש העמוד), וסינון לפי צבע/קצב בסרגל הצד שחל על כולם:

- **סקירה** – אחוז נקודות, 30 הימים האחרונים מול התקופה שלפניהם, כמה משחקים כוללים טעות בפתיחה ומה היא עולה, לבן מול שחור, שלוש הפתיחות שהכי כדאי לעבוד עליהן
  (לפי "נקודות שאבדו" = משחקים × (ממוצע − אחוז הנקודות בפתיחה)), גרף דירוג וגרף של המסע שבו מגיעה הטעות הראשונה.
- **נקודות חולשה** – לכל צבע: סיכום החולשות והחוזקות המובהקות וגרף של כל הפתיחות לפי הפער מהממוצע בצבע.
- **הפתיחות שלי** – עץ הפתיחות עם סכומים (⚠ = בעייתית), וניווט להמשכים. בחירת שורה פותחת את הטעויות בפתיחה, ולוח שאפשר לעבור בו מסע‑מסע עד רגע הטעות.
- **טעויות חוזרות** – כרטיס לכל טעות שחזרה ב‑3+ משחקים: לוח שמראה את הטעות עם חצים, או את **הקו הנכון** / **קו העונש**
  מסע אחר מסע (התחלה / הקודם / הבא / סוף), מה שוחק מול מה עדיף, **הסבר** (מה הולך בקו של המנוע, שנמשך עד שאין יותר הכאות או שחים פתוחים, ופרש מול רץ נחשב החלפה שווה:
  "פרש תמורת פיון", "החמצה" רק כשהמסע ששוחק עצמו לא מפסיד, "יש פיצוי" כשהמנוע עדיין מעריך את העמדה כשקולה (כמו בגמביט),
  ומשפט שמבוסס על ההערכה כשטענת החומר גדולה בהרבה מהערכת המנוע, או "אין הפסד חומר אבל העמדה נהיית קשה"), **קו העונש** ו**הקו הנכון** של המנוע (`chessapp/lines.py`,
  נשמרים בטבלת `pv_v1`), **מה היריבים ענו בפועל** והציון אחרי כל תשובה, **המחיר בנקודות** (משחקים × (ממוצע בצבע − ציון במשחקים האלה); כשהוא שלילי מוצג "רווח בפועל" עם הסבר),
  **בדיקה "ברמה שלך"** (כשיש טוקן): המסע ששוחק מול המסע של המנוע במשחקי Lichess בטווח הדירוג של השחקן (בליץ ורפיד).
  אם המסע ששוחק נפוץ (100+ משחקים) ומשיג לפחות 50% ולפחות כמו המסע של המנוע, הכרטיס מסומן "עובד ברמה שלך"
  (למשל ה‑Alien Gambit בקארו־קאן, 6.Nxf7). אפשר להסתיר מסעים כאלה ברשימה, והתרגול לא כולל אותם.
  המסע הרגיל בעמדה (או "אין מסע קבוע" כשיש תיקו), מצב הלמידה ולינק ללוח הניתוח של Lichess. ייצוא PGN ל‑Lichess Study (עד 60 עמדות): הקו של המנוע הוא הקו הראשי,
  המסע ששוחק הוא וריאציה עם ההסבר וקו העונש, ותשובות היריבים בפועל מופיעות כווריאציות נוספות.
- **תרגול** – רק טעויות חוזרות (3+ משחקים; 2+ אם אין כאלה), כולן או לפי פתיחה; בוחרים מבין 4 מסעים (הטוב ביותר, הטעות ששוחקה, ושניים אקראיים), הבדיקה מול המסע הראשון של Stockfish.

ערכת העיצוב ב‑`.streamlit/config.toml`. מילון מונחים מופיע בסרגל הצד ("איך לקרוא את הנתונים").

## הנחות

1. Stockfish משמש לכל המשחקים באופן אחיד; ה‑evals שמגיעים מ‑Lichess (בחלק מהמשחקים) לא נעשה בהם שימוש, כדי לשמור על עקביות.
2. משחקים לא סטנדרטיים (וריאנטים / עמדת פתיחה מותאמת) מדולגים. ultraBullet נספר כ‑bullet.
3. מטמון ה‑FEN מתעלם ממונה המסעים (4 השדות הראשונים) כך שטרנספוזיציות משתפות הערכות.
4. Lichess חוסם (404) בקשות עם User‑Agent ברירת מחדל של curl, לכן מוגדר User‑Agent מזהה.
5. **Opening Explorer**: ה‑API (`explorer.lichess.ovh`) מחזיר כיום 401 ללא טוקן (ראו "הרצה" למעלה: `data/lichess_token.txt` או `LICHESS_TOKEN`). שגיאות רשת, 401/403/429 ותשובות לא צפויות מוצגות בכרטיס עם הסיבה, ולא נשמרות במטמון. אין טוקן במערכת, ולכן בהרצה ללא `LICHESS_TOKEN`
   הדשבורד מציג את המסע ששוחק ואת המסע הטוב ביותר של Stockfish בלבד, והערה שנתוני ה‑Explorer חסרים.
   עם טוקן: הטבלה (מסעים נפוצים ואחוזי הצלחה ברמה דומה – הטווח של היוצר ושל הטווח שמעליו, קצבי blitz/rapid) תופיעה אוטומטית ותישמר במטמון.
6. כל המשחקים כמעט בליץ, ולכן הפילוח לפי קצב כמעט ריק מעבר לבליץ.

## למידה לאורך זמן

לכל טעות (עמדה + מסע שגוי) נספרים כל הביקורים שלך בעמדה, בסדר כרונולוגי: **הגעתי**, **טעיתי**, **% טעיתי**, ו‑% מתוך 5 הביקורים האחרונים.
סטטוס: *מעט נתונים* (פחות מ‑3 ביקורים), *נלמד* (אחרי הטעות האחרונה הגעת לעמדה ≥3 פעמים ולא חזרת עליה), *עדיין חוזר* (הביקור האחרון היה טעות), *בדרך לתיקון* (1–2 ביקורים נקיים מאז).
טעויות "שנלמדו" מוסתרות כברירת מחדל (תיבת סימון) ברשימות ובתרגול. "נלמד" אומר שלא חזרת על אותו מסע שגוי, לא בהכרח ששיחקת את המסע הטוב ביותר.
בטבלת הפתיחות: "שגיאה נפוצה" = הטעות הראשונה הנפוצה ביותר אחרי רצף הפתיחה, ו‑"% משחקים עם שגיאה זו" = חלקה מכלל משחקי הקבוצה.
